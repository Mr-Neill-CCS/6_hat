SIX THINKING HATS – WEB VERSION (V1)

LOCAL TESTING
1. Keep index.html, styles.css, and app.js together in the same folder.
2. Double-click index.html. It should open in your normal web browser.
3. No internet connection or web server is required for this version.

GITHUB PAGES
1. Create a new GitHub repository (for example: six-hats-assessment).
2. Upload index.html, styles.css, and app.js to the repository root.
3. In GitHub: Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Choose the main branch and / (root), then Save.
6. GitHub will provide the public Pages URL.

BLACKBAUD
Once published, use the GitHub Pages URL as a link or iframe source if your Blackbaud content editor permits iframe embeds.

FILES
- index.html = page structure
- styles.css = appearance/layout
- app.js = questions, navigation, scoring, and results

SCORING
The six raw hat scores are averages of five questions each. V1 intentionally matches the spreadsheet's approximate percentile method: each hat average is converted to a z-score using the mean and sample standard deviation of that student's 30 responses, then mapped to the normal distribution.

These are NOT population percentiles. The page labels them as relative scores and explains this on the results screen.
